# MMORPGEngine

Shared code used internally by the Server, Client and Editor — world data,
rendering, networking helpers. It's a library, not an app: there's nothing
to run here on its own.

If you're building or running one of the other three apps, this gets built
automatically along with it.

Technical details: [`Doc/MMORPGEngine.md`](../Doc/MMORPGEngine.md).
